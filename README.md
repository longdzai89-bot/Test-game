# Tu Tiên Online — TheAnhh

Full-stack cultivation game platform: public web, admin web, Termux CLI and Capacitor APK.

## Quick start

```bash
cp .env.example .env
bash setup.sh
npm run dev
```

MongoDB must be available at `MONGODB_URI`. Admin CLI:

```bash
node server/src/cli/admin-cli.js
```

See `.env.example` for configuration.
